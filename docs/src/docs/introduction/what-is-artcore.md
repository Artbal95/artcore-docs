# What is ArtCore?

ArtCore is an architectural system for scalable React applications.

It is based on the **Layered Modular Design (LMD)** approach — an architecture built around strict boundaries, modularity, and predictable scalability.

Unlike common feature-based structures, ArtCore was designed for long-lived projects and teams consisting of many developers.

## Why ArtCore was created

Most frontend architectures work well only in small projects.

Problems start as the application grows:

* shared folders turn into chaos
* business logic starts to duplicate
* dependencies become unpredictable
* it becomes unclear who is responsible for what
* refactoring becomes expensive and risky
* teams start conflicting within the codebase

ArtCore was created as an attempt to solve exactly these scaling problems.

## Core ideas

ArtCore is built around several principles:

* layered architecture
* modular isolation
* strict dependency boundaries
* predictable composition
* business-oriented structure
* team-friendly scalability

The main goal is to keep large React applications maintainable even after years of development.

## What is Layered Modular Design

Layered Modular Design (LMD) combines ideas from:

* Domain-Driven Design (DDD)
* layered architecture
* modular systems
* scalable frontend engineering

As a result, you get a structure where:

* features remain isolated
* responsibilities between layers are clear
* architecture does not collapse as the project grows
* teams can work independently

## Who ArtCore is for

ArtCore is suitable for:

* large React applications
* long-lived products
* enterprise systems
* SaaS platforms
* dashboard projects
* CRM systems
* teams of multiple frontend developers
