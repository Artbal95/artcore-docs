# Установка

Самый быстрый способ начать — использовать [ArtCore CLI](/ru/docs/cli/intro).

ArtCore позволяет начать разработку масштабируемых приложений без долгой ручной настройки проекта.

<ArtCoreCallout variant="warning" title="Требования">
Перед началом убедитесь, что у вас установлено:

* Node.js >= 20
* npm, yarn или pnpm
</ArtCoreCallout>

## Создание проекта

::: code-group
```bash [npm]
npx create-art-app my-art-app
```

```bash [yarn]
yarn create art-app my-art-app
```

```bash [pnpm]
pnpm create art-app my-art-app
```
:::

<ArtCoreDetails title="Можно использовать без имени проекта">

::: code-group
```bash [npm]
npx create-art-app
```
```bash [yarn]
yarn create art-app
```
```bash [pnpm]
pnpm create art-app
```
:::
Если имя проекта не указано, CLI перейдёт в интерактивный режим:

<ArtCoreTerminalType
  text="? Enter project name:"
  value="my-art-app"
  rewriteValue="my-awesome-app"
/>

После этого ты сможешь ввести название прямо в терминале.
</ArtCoreDetails>

## Выбор типа проекта
После указания имени проекта CLI предложит выбрать тип проекта:

```bash
? Choose project type:
❯ Pure React
```

Каждый тип определяет базовую архитектуру и набор предустановленных зависимостей.
Подробное описание всех типов проектов и архитектурных пресетов доступно [здесь](/ru/docs/templates/intro)

<ArtCoreCallout variant="info" title="Pure React">
Минимальный стартовый шаблон без лишних библиотек и архитектурных надстроек.

Идеально подходит, если ты хочешь:
* начать с чистого React
* самостоятельно собрать архитектуру
* использовать ArtCore постепенно
* избежать лишних зависимостей
</ArtCoreCallout>

## Установка зависимостей

Во время создания проекта CLI спросит, нужно ли установить зависимости автоматически:

```bash
? Install dependencies now? (Y/n)
```
Если ты выберешь <b><i>Yes</i></b>, CLI автоматически выполнит установку через выбранный пакетный менеджер.

Если выберешь <b><i>No</i></b>, ты сможешь установить зависимости вручную позже:

::: code-group
```bash [npm]
npm install
```
```bash [yarn]
yarn install
```
```bash [pnpm]
pnpm install
```
:::

<ArtCoreCallout title="Полезная информация">
Это полезно, если ты хочешь сначала проверить структуру проекта или установить зависимости позже вручную.
</ArtCoreCallout>

## Запуск проекта

После успешного завершения всех шагов перейди в директорию проекта:

```bash
cd my-art-app
```

И запусти проект в режиме разработки:

::: code-group

```bash [npm]
npm run dev
```

```bash [yarn]
yarn dev
```

```bash [pnpm]
pnpm dev
```

:::

После запуска приложение будет доступно по адресу localhost:5173
