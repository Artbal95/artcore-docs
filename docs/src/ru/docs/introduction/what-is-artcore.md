# Что такое ArtCore?

ArtCore — это архитектурная система для масштабируемых React-приложений.

Она основана на подходе Layered Modular Design (LMD) — архитектуре, построенной вокруг строгих границ, модульности и предсказуемого масштабирования.

В отличие от обычных feature-based структур, ArtCore создавался для проектов, которые растут годами и команд, состоящих из множества разработчиков.

::: warning Быстрый старт доступен
Если вы уже знаете, что хотите — переходите сразу к [установке](/ru/docs/getting-started/installation) и начните использовать ArtCore на практике.
:::

## Почему появился ArtCore

Большинство frontend-архитектур хорошо работают только в маленьких проектах.

Проблемы начинаются с ростом приложения:

- shared-папки превращаются в хаос
- бизнес-логика начинает дублироваться
- зависимости становятся непредсказуемыми
- становится непонятно, кто за что отвечает
- рефакторинг становится дорогим и рискованным
- команды начинают конфликтовать в кодовой базе

ArtCore был создан как попытка решить именно проблемы масштабирования.

## Основные идеи

ArtCore строится вокруг нескольких принципов:

- слоистая архитектура
- модульная изоляция
- строгие dependency boundaries
- предсказуемая композиция
- business-oriented структура
- удобное масштабирование команд

Главная цель — сделать большие React-приложения поддерживаемыми даже спустя годы развития.

## Что такое Layered Modular Design

Layered Modular Design (LMD) объединяет идеи:

- Domain-Driven Design (DDD)
- layered architecture
- модульных систем
- scalable frontend engineering

В результате получается структура, в которой:

- фичи остаются изолированными
- ответственность между слоями понятна
- архитектура не разваливается при росте проекта
- команды могут работать независимо друг от друга

## Для кого создан ArtCore

ArtCore подходит для:

- больших React-приложений
- долгоживущих продуктов
- enterprise-систем
- SaaS платформ
- dashboard-проектов
- CRM-систем
- команд из нескольких frontend-разработчиков
